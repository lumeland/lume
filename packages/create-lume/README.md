# create-lume

Script to create Lume sites.

```
npm create lume
pnpm create lume
yarn create lume
```

Create a site in a specific folder (i.e: `my-blog`):

```
npm create lume my-blog
pnpm create lume my-blog
yarn create lume my-blog
```

Create a site with a theme (i.e: `@lumeland/theme-simple-blog`):

```
npm create lume -- --theme=@lumeland/theme-simple-blog
pnpm create lume --theme=@lumeland/theme-simple-blog
yarn create lume --theme=@lumeland/theme-simple-blog
```
